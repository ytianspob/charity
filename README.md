# 社区公益服务管理系统

## 项目简介
本项目是一个基于Thinkphp 6.1的社区公益服务管理系统，旨在为社区居民、志愿者及公益组织提供一个高效、透明、便捷的公益服务平台。系统围绕“发布—参与—反馈”的业务流程，构建完整的公益活动闭环管理机制。

系统核心功能包括：公益项目与求助信息发布及浏览、活动报名管理、资金与物资捐赠记录维护、评论互动、站内消息通知以及用户实名认证与权限控制。

---

## 功能模块

### 公益信息管理
- 公益项目发布与浏览
- 求助信息发布与查看
- 分类筛选与搜索

### 活动报名管理
- 在线报名
- 报名审核与管理
- 活动参与记录

### 捐赠管理
- 资金捐赠记录
- 物资捐赠登记
- 捐赠信息展示

### 评论与互动
- 评论功能
- 回复与交流

### 消息通知
- 系统通知
- 用户消息

### 用户与权限管理
- 用户注册与登录
- 实名认证
- 权限控制（用户 / 管理员）

### 后台管理
- 用户管理
- 项目管理
- 活动管理
- 捐赠管理
- 评论管理
